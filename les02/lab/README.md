Отчёт по лабораторной работе №1
«Gradle. Базовое приложение Spring»

Цель работы:
Приобретение практических навыков установки и настройки автоматизированной системы сборки Gradle, управления зависимостями Spring Framework, а также проектирования кроссплатформенного консольного Java-приложения со слабосвязанной архитектурой, предназначенного для чтения и разбора данных из внешних CSV-источников.

Ход выполнения:

Выполнена загрузка и установка дистрибутива Gradle.

Путь к исполняемым файлам Gradle (каталог bin) добавлен в системную переменную PATH для обеспечения доступа из любой директории командной строки.

Создан новый проект на базе системы сборки Gradle и JDK Axiom JDK 21.0.10.

В конфигурационном файле build.gradle подключены необходимые зависимости Spring Framework.

Сформирована структура проекта, включающая следующие компоненты:

Main — точка входа в приложение;

AppConfig — класс конфигурации контекста Spring;

MessageProvider — интерфейс для получения данных;

MessageRenderer — интерфейс для отображения данных;

CarServiceMessageProvider — класс, реализующий чтение и парсинг CSV-ресурса;

OutMessageRenderer — класс, реализующий вывод информации в консоль.

В каталоге resources размещён файл resource.csv, содержащий данные о товарах.

Выводы:
В процессе выполнения работы успешно освоены процедуры развёртывания локального окружения Gradle 9.5.0 и его интеграции с операционной системой через переменные среды. Реализовано базовое приложение на платформе Java 21 с использованием Spring Framework, демонстрирующее применение принципа инверсии управления при связывании компонентов через интерфейсы. Получены практические навыки потокового чтения данных посредством InputStream и построчной обработки табличных файлов в формате CSV.
